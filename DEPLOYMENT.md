## Замеры доступа к Sport Hub

| Исполнитель | Результат |
|---|---|
| Компьютер пользователя | TCP + TLS + HTTP 200: 0,1 с; полный авторизованный снимок: около 9–14 с |
| GitHub Ubuntu x64 | TCP timeout через 8 с; три попытки API завершились ошибкой |
| GitHub Ubuntu ARM | TCP timeout через 8 с |
| GitHub Ubuntu Slim | TCP timeout через 8 с |
| Vercel Frankfurt (`fra1`) | TCP timeout через 10,13 с |
| Vercel Mumbai (`bom1`) | TCP timeout через 10,22 с |

Из этих измерений нельзя установить точную причину сетевой недоступности или утверждать, что закрыты все зарубежные IP. Подтверждено отсутствие соединения с перечисленных хостов и успешное соединение локально.

При работе через GitHub self-hosted runner на компьютере пользователя сохранятся все cron-проверки, но компьютер должен оставаться включённым и не спать. Альтернатива для круглосуточной работы — сервер с подтверждённым доступом к Sport Hub, например в Казахстане. Обычный домен Vercel не устраняет ограничения соединения функции с исходным сайтом.
